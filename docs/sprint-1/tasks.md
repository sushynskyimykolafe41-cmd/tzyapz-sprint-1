## Структура та управління задачами
Управління задачами команди та відстеження прогресу Спринту 1 здійснюється у Google Sheets (вкладка «Розподіл задач Спринт 1»).

### Основні блоки таблиці:
* **Task ID & User Story:** прив'язка кожної технічної задачі до відповідної User Story з беклогу.
* **Виконавець (Assignee):** розподіл задач між членами команди згідно з ролями Спринту 1.
* **Оцінка трудомісткості (Hours/Story Points):** плановий та фактичний час на виконання.
* **Статуси виконання:** `To Do` / `In Progress` / `In Review` / `Done`.
