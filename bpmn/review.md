# Протокол рецензування BPMN-моделей (Спринт 1)
**Рецензент:** Іван Баришполь (Скрам-майстер)
**Продукт:** «АвтоРейт»

## 1. Рецензування моделі: `01_registration` (Реєстрація і вхід)
| № | Пункт чек-листу (4.9) | Так/Ні | Зауваження / Виправлення |
|---|---|---|---|
| 1 | Наявність початкової та кінцевої подій у пулах | Так | - |
| 2 | Відсутність «висячих» елементів (кожна дія має потік) | Так | - |
| 3 | Потоки управління не перетинають межі пулів | Так | - |
| 4 | Шлюзи-розгалуження підписані, є умови | Так | - |
| 5 | Паралельні розгалуження закриті синхронізацією | Так | - |
| 6 | Шлюзи за подіями налаштовані правильно | Так | - |
| 7 | Коректні назви (дії — дієслово+об'єкт, події — стан) | Так | - |
| 8 | Доріжки відповідають ролям з легенди «АвтоРейт» | Так | - |
| 9 | Артефакти даних приєднані асоціаціями | Так | - |
| 10| Модель читається зліва направо, відповідає легенді | Так | - |
**Статус моделі:** Затверджено.
